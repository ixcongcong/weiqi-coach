# 围棋对战教练

离线围棋学习与对战：内置 KataGo 神经网络（g170 b10c128，转成 ONNX，用 onnxruntime-web 在浏览器里运行）+ PUCT 搜索，另有蒙特卡洛（RAVE）引擎用于低难度和后备，不联网、不调用大模型。网页版可“添加到主屏幕”离线使用：<https://ixcongcong.github.io/weiqi-coach/>

- **对战**：9/13/19 路、5 档难度、AI 胜率控制、让子与贴目、吃子棋；逐手讲解、提示、形势判断、回看（可试下，不改变对局）、提问、新手辅助；每一盘都保存在本机，可导出/导入。
- **结束当前局（3.10）**：围棋、中国象棋和国际象棋的对战操作栏都可一键停止本局，AI 思考期间也可结束（围棋还支持在数目计算期间结束）。已落子棋谱保留在“我的对局”，标记“未计胜负”，不修改等级分；可回看或新开一局。刷新后仍保持结束，不自动续下。零手空局不新增棋谱。
- **自由布局（3.11）**：三种棋都可拖动棋盘与 AI 解答之间的分隔条，手机竖屏上下调整、电脑横屏左右调整，连续按像素分配空间。扩大解答区域时棋盘自动适应剩余空间；也可输入任意整数像素宽度（96–2400px）或用加减按钮细调棋盘，解答区域反向调整。不再只能选择比例档位。大棋盘仍可平移查看，拖动不会落子；长解答在自己的区域内滚动。讲解文字可独立切换 100% / 125% / 150%，显示设置按棋种保存，分区位置按横竖屏分别保存；仅改变显示，不改变棋局或 AI 难度。
- **学习**：《弈》系统课程 54 课（来自作者的“弈”项目，`tools/yi/`）、27 课动画演示课、39 局名局（9/13/19 路），猜棋模式。
- **练习**：36 道吃子与死活题，答错时演示对方的应法。

## 生成数据

```sh
node tools/make_games.js   # 生成 web/games.js 与 web/problems.js，并用引擎验证每一课、每一题、每一局
```

课程与题目定义在 `tools/curriculum.js`，名局棋谱在 `tools/sgf/`。

Android 外壳（`build.sh`、`src/`）已停止维护，手机请直接使用网页版。

## 本地验证

无需安装依赖，用 Node.js 运行控制器和显示设置回归检查：

```sh
node --test tools/test_end_game.js tools/test_cc_end_game.js tools/test_board_view.js
```

截至 3.11，56 项检查覆盖三种棋的中途结束、刷新恢复、延迟 AI 回调取消、升变/认输对话框、无胜负归档，以及自由像素尺寸、双向分区联动、分隔条拖动/键盘/焦点、横竖屏切换与保存、极短窗口默认布局限制、平移/双指防误落子、尺寸变化后的棋盘坐标映射。浏览器本地验证包含桌面左右分区、围棋像素输入 367px→500px 时 AI 区域反向变化，以及 393×852 手机尺寸模拟中向上拖动后解答区增大、棋盘自动缩小并刷新恢复；这些检查不代表真实 Android/iOS 设备验收，也不代表已发布到上述公开网址。

## 调整界面大小

- 拖动棋盘和解答之间的小短条即可自由分配空间。解答区变大，棋盘随之缩小；往相反方向拖动即可还原空间。
- 棋盘下方的像素输入框可输入精确宽度，滑块支持 1px 精度，加减按钮每次调整 20px；设置时两区联动。超过视图区的棋盘可以平移查看。
- “适应屏幕”让棋盘适应当前分区；“默认布局”恢复默认分区和自动适应，保留文字大小及当前棋局。也可双击分隔条恢复默认。
- 分隔条可用方向键调整（每次 10px，按住 Shift 每次 50px）；横屏左箭头、竖屏上箭头扩大解答区。

## 神经网络引擎

- 网络：KataGo g170 系列（`g170e-b10c128`、`g170-b6c96`，来自 katagoarchive.org），用 `tools/katago_to_onnx.py` 转成 ONNX，放在 `web/models/`。
- 输入特征在 `web/nn.js` 里实现（与 KataGo V7 特征一致：气、打劫、最近 5 手、征子搜索、Benson 活棋区域、贴目奇偶），已用 `katago kata-raw-nn` 逐点核对，输出误差在 1e-6 量级。
- `web/nnworker.js` 在 Web Worker 里跑 onnxruntime-web（`web/ort/`，WebAssembly），做 PUCT 搜索与单次评估；service worker 加跨源隔离头，支持时自动用多线程。
- 转换命令：`python tools/katago_to_onnx.py g170e-b10c128-….bin.gz web/models/b10.onnx`（需要 numpy、onnx）。
