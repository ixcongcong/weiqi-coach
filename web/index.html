对局设置

吃子棋是刚学围棋时最好的练习：不用管地盘，谁先吃到规定数量的子谁赢，专门练习“气”和吃子。
胜率控制：100 = AI 全力下；调低后 AI 会挑选让自己胜率接近设定值的下法（越低越让着你）。

欢迎！刚开始学围棋吗？

推荐按这个顺序来，每一步都不难：

  1. 学习 → 《弈》第 1、2 阶段：认识棋盘、气、提子、禁着点、打劫，每课 10 分钟左右，课后有练习。
  2. 练习 → 第 1 级：吃子入门题，边做边巩固。
  3. 对战 → 吃子棋：先吃到子的一方赢，练习对“气”的感觉。
  4. 学习 → 《弈》第 3、4 阶段：吃子手筋和死活对杀，配合“动画演示课”和第 2、3 级练习。
  5. 对战 → 9 路正式对局：难度选“入门”，打开“讲解”和“新手辅助”，下完点“回看”复盘。
  6. 棋谱 → 名局：先看 9 路职业对局，打开“猜棋”先想再看。

以后随时可以点右上角“说明”再看这份路线。

使用说明

推荐学习路线（刚开始学）

  1. 学习 → 《弈》第 1、2 阶段（认识棋盘、气、提子、禁着点、打劫）
  2. 练习 → 第 1 级吃子题
  3. 对战 → 新局 → 玩法选“吃子棋”
  4. 学习 → 《弈》第 3、4 阶段（吃子手筋、死活对杀），练习第 2、3 级
  5. 对战 → 9 路正式对局（入门难度，打开讲解和新手辅助）
  6. 棋谱 → 名局（先看 9 路，打开猜棋）

对战

  • 落子：手指按住棋盘会出现半透明的预览子和蓝色十字线，松开即落子。怕点错可以勾选“确认落子”，点两次才落子。
  • 新手辅助：只剩一口气（被叫吃）的棋子会套上红圈；你要下一手会让自己被叫吃的棋时，会先提醒你，再点一次才下。
  • 讲解：每下一手都有点评——最佳 / 好棋 / 可以 / 缓手 / 恶手，原因是什么，下得不好时告诉你更好的下法。
  • 回看：想回到前面看看、想一想时用。可以一步步往前往后看，还可以在那个局面上“试下”几手，真正的对局不会被改变。看完点“回到当前”继续下。它和“悔棋”不同：悔棋会真的把棋退回去。
  • 提示 / 形势：推荐下一手；显示双方地盘并估算谁领先。
  • 悔棋：真正退回到你的上一手，重新下。
  • 停一手：双方都没有好地方下时才停。双方连续停一手就终局数子，数子时点棋子可以切换死活。
  • 新局：选择玩法（正式对局 / 吃子棋）、棋盘、执黑执白、让子、贴目、AI 难度，以及“AI 胜率控制”——调低后 AI 会故意放水。只想改难度，就点“只改 AI 设置”。

学习

  • 《弈》系统课程：9 个阶段 54 课，从第一次下棋一直到中盘、定式、官子和独立实战。每课有学习目标、讲解和课后练习（点棋盘、选择、填数字、按步走），全部答对这一课就标上“已学”。题目里的数字是点位编号，点“显示编号”可以在棋盘上对照。
  • 动画演示课：27 课，把气、吃子手筋、死活、布局等用一步步的动画演示出来，适合配合《弈》的对应章节看。
  • 棋谱（单独的标签页）：9 路、13 路、19 路职业对局，小棋盘从短的排起；19 路有耳赤之局、吴清源、聂卫平擂台赛、AlphaGo 等名局，重点手有专门讲解。你自己下过的每一盘也在这里（“我的对局”）。
  • 下一手 / 上一手：一步步看；拖动滑块快速跳转；电脑上可以用键盘左右方向键。自动播放：每 3.5 秒走一步。
  • 猜棋：先在棋盘上点你认为的下一手，再揭晓答案，猜错的位置用蓝色叉号标出。

我的对局

  • 你下的每一盘棋都会自动保存在本机（下完、认输、或者没下完就开了新局都会保存）。在“棋谱”标签页的“我的对局”里可以一步步回看，每一手都有 AI 讲解，也可以打开猜棋。
  • 在“我的对局”里可以“导出全部对局记录”存成一个文件，换设备后“导入”合并，不会删除已有的记录。

练习

  • 分 3 级：吃子入门、吃子技巧、对杀与死活。在棋盘上点你的答案，对了会演示完整的变化，错了会告诉你对方怎么应。
  • 卡住了点“提示”，还不会就点“看答案”。做完的题会标上“已完成”。

提问

  • 点“提问”可以问：现在谁领先？ 下一手下哪里好？ 这里下怎么样？（再点棋盘上一个空点）这块棋活吗？（再点一块棋）哪块棋最危险？
  • 也可以输入文字，例如“什么是打劫”“怎么做活”。引擎是离线的，不能像聊天机器人那样理解任意问题。

同步

先点右上角的用户名选择用户（可以从家里学习中心添加已有用户，例如初九），再点“同步”。之后只要在家里的网络里打开本应用，就会自动同步：每一盘对局记录、练习进度、《弈》的课程进度都会和其它设备、《弈》App 合并，不会删除任何记录。第一次使用需要在设备上安装一次家里的证书，步骤在同步窗口里。

关于离线和更新

AI 是内置在程序里的围棋引擎，完全离线运行，不联网、不调用大模型。第一次打开后，所有文件都保存在设备上，关掉以后从主屏幕图标打开照样能用，不需要一直开着。有网时打开，会自动下载新版本，底部提示“新版本已下载好”时点“立即更新”即可。

同步（家里的 Mac 学习中心）

对局记录、练习进度和《弈》的课程进度，会和家里 Mac 上的“弈 · 学习中心”合并同步（只合并，不删除任何记录）。同一个用户在 iPad、手机、《弈》App 上的进度都会汇总在一起。

第一次使用：在这台设备上安装家里的证书

学习中心使用 https，需要设备信任家里 Mac 生成的根证书（每台设备只需做一次）：

  1. 连上家里的 Wi-Fi，用浏览器打开 http://VincentdeMac-mini.local:8766/ca.crt（安卓打不开时用 http://192.168.1.9:8766/ca.crt）。
  2. iPad / iPhone：允许下载描述文件 → 设置 → 通用 → VPN 与设备管理 → 安装；再到 设置 → 通用 → 关于本机 → 证书信任设置，打开这个证书的开关。
  3. 安卓：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书，选择下载的文件。

用户

每个用户有自己的对局记录、练习和课程进度。用户和家里 Mac 上“弈 · 学习中心”的用户是同一套：在这里选中的用户，同步时就合并到学习中心里同名同 ID 的用户（例如《弈》App 里的初九）。

AI 老师设置

关于棋盘的精确问题（气、地盘、断点、能吃的棋……）由本机引擎离线回答。其它问题交给大模型，并附上引擎算好的局面事实。按下面的顺序尝试，前一个不可用就用下一个。
